# Security Policy

## Supported versions

This project currently supports security fixes on the latest `main` branch.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately via GitHub Security Advisories:
- https://github.com/vincyf1/url-shortener/security/advisories/new

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

We will acknowledge valid reports and aim to provide an initial response within 5 business days.
